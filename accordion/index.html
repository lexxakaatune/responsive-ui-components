Frequently Asked Questions

What is included in this UI kit?

Each component folder contains its own HTML and CSS files. You can copy any single folder into your project without dragging in unused code. No frameworks, no build tools required.

Do I need JavaScript to use these components?

Most components are pure CSS. Only the navbar, modal, and alert use small vanilla JS snippets. Everything else works without scripts.

Can I customize the colors easily?

Yes. Every stylesheet starts with CSS custom properties in :root. Change a few variables and the entire component updates to match your brand.

Is this accessible for screen readers?

We use semantic HTML and ARIA attributes where they add value. The accordion uses native <details> and <summary> elements, which are announced correctly by assistive technology without extra markup.

What browsers are supported?

All modern versions of Chrome, Firefox, Safari, and Edge. We use standard CSS like Flexbox, Grid, and custom properties — no experimental features.
